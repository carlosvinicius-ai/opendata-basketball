Analytical Framework: BAV + SCI = FSPV

Ball Action Value (BAV): Calibrated XGBoost estimating ΔP(score | state) on ordered ball-touches, passes, shots, picks, and drives.
Space Creation Index (SCI): Inductive GraphSAGE GNN capturing multi-agent spatial geometry, attributing off-ball player gravity via Input × Gradient.
Full Spectrum Player Value (FSPV): Standardized z-score synthesis: FSPV = 0.5 × BAV_z + 0.5 × SCI_z. Zero-leakage validated against official ACB 2025/2026 aggregates.
